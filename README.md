# Masters Assignment 1

This repository contains the Python solutions for Masters Assignment 1.

## Questions

1. **Rate-Limited Decorator**
   - Explains and fixes the `UnboundLocalError`.
   - Implements a corrected rate-limit decorator.

2. **Event Dispatcher**
   - Implements the Observer Pattern.
   - Supports subscribe, unsubscribe and dispatch.
   - Preserves callback registration order.
   - Handles callback exceptions without stopping subsequent callbacks.

3. **Typed Descriptor**
   - Implements runtime type checking using a Python descriptor.
   - Uses `__set_name__` to automatically create the storage attribute name.

4. **Product of Multiples**
   - Uses a `for` loop and `range()` to calculate the product of multiples.

## How to Run in PyCharm

Open this folder as a project in PyCharm.

Run each file separately:

```text
question1_rate_limit.py
question2_event_dispatcher.py
question3_typed_descriptor.py
question4_product_of_multiples.py
```

Make sure Python 3 is selected as the project interpreter.
